# 猫咪花色生育小游戏

## What We're Building

一个网页小游戏 demo：玩家捏两只不同花色纹理的猫咪，模拟生育后一窝后代的花色可能。核心循环是「调两只亲本 → 抽一窝小猫 → 点开看为什么长这样」。

不做养成、不做多代族谱、不做真实基因位点教材。目标是半真实遗传玩具：规则能讲给普通人听，结果又足够花、足够意外。

## Why This Approach

讨论过的方向：

- **半真实遗传玩具（已选）：** 红/黑/玳瑁尽量贴近性连锁，其余层简化抽签。
- 偏科普真实位点：捏猫会变成填基因表，玩具感差。
- 纯可爱调色盘：好看但讲不清「为什么」。
- 小型猫舍养成：超出 demo，延后。

交互上选了 **自己调两只亲本再生育**，而不是只给预设亲本对。视觉选了 **扁平插画色块分层**，而不是像素或照片质感。

## 已确认选择

| 主题 | 决定 |
|---|---|
| 体验 | 半真实遗传玩具 |
| 主循环 | 捏猫：自己调两只亲本的底色 / 纹样 / 白斑 |
| 画面 | 扁平插画，色块 + 图层叠纹样 |
| 解释 | 三层对照：底色 / 纹样 / 白斑，每层一句人话，可和爸妈并排看 |
| 性别 | 要。红/玳瑁简化性连锁；玳瑁几乎只出现在母猫 |
| 一窝 | 4–6 只；同一对可连生几窝以感受概率 |
| 对照词汇 | 常见 / 少见，不出现 B、O、D 等基因符号 |

## Key Decisions

- **花色只分三层：** 底色（黑 / 红 / 玳瑁，加深浅稀释）、纹样（纯色 / 虎斑 / 重点色）、白斑（无 → 手套胸巾 → 半白 → 大面积白）。白多了的玳瑁看起来像三花。
- **玩家捏的是表型，不是基因型。** 惊喜来自隐藏携带与抽签，不要让玩家填等位基因。
- **性别是红猫梗的关键：** 一窝里同时出现橘公、黑公、玳瑁母，玩家自己能得出规则。
- **v1 不把子代升为亲本。** 只改当前两只亲本再点生育；升亲本会滑向养成，明确延后。
- **不做：** 品种标准、银尖/烟色、长毛短毛、账号、战斗或养成数值、完整真实基因表。

## 简化遗传意图（给玩家的感觉）

- 底色：红走性连锁——公猫红或黑二选一，母猫可以红、黑或玳瑁。
- 纹样：虎斑、重点色对纯色更「常见」；纯色亲本仍可能生出带纹的（隐性藏着）。这是玩具向，不必和真实虎斑显性完全一致。
- 白斑：靠近父母的「量」，每只小猫再抖一点，避免整窝克隆。
- 公玳瑁：极少数隐藏彩蛋。

## Open Questions（开发前已钉死）

- 子代能否拖去当亲本 → **v1 否**
- 一窝只数 → **4–6，实现时可取 5 为默认**
- 「再生一窝」→ **要**，替换当前这窝，不积累族谱
