# 现实依据与遗传模型修正

用户要求基于现实简化，不能用任意抽签取代主要遗传关系。本文件取代此前文档中独立全白开关遗传、固定有纹概率及惊喜纹样池的设计。

## 已修正

- 名称使用暖棕色、浅红棕、浅暖灰、浅米棕；编辑说明保留巧克力、肉桂、丁香、浅鹿等专业名称。
- KIT 使用无白、白斑、显性全白三类等位信息，每个后代各继承双亲一份。显性全白优先表达；没有显性全白时，白斑版本表达局部白毛；无白版本不会凭空产生白斑。
- 白猫初始化不再固定单份：无白斑设置时模拟分配 25% 双份显性全白、75% 单份加无白；设置潜在白斑时分配全白/白斑。非白白斑亲本初始化等概率一份/两份白斑。所有这些比例仅是模拟先验，并非种群频率。不能根据毛色确定真实基因型。
- 有无纹样表达、细条/经典纹、毛色分段分别建模并从父母传入。非橘色无纹双亲不再凭空生出可见虎斑；经典纹双亲不再凭空出现细条纹。橘色会显纹，纯色选项禁用并自动归一到细条纹。
- 重点色独立于纹样；原有性连锁、稀释与黑棕色系关系保留。
- 每只后代 Trace 保存实际 KIT、纹样、色素信息，解释依据记录生成。

## 明确的近似与范围

- KIT 不包括白化、其他白斑成因或白手套的专门位点。白斑面积与位置不是由份数直接决定，本版只在确认继承白斑后做外观近似。
- 斑点修饰不是已确定的简单单基因模型。这里以父母修饰倾向平均作为可遗传外观近似，不再从全纹样池随机抽取。不能用这一规则预测真实斑点概率。
- 显性纹样的初始携带信息使用模拟先验，纯色可隐藏纹样结构信息；调整无关属性或连续生育时保持稳定。
- 玳瑁橘色区域的弱纹尚未单独细画；白猫隐藏底色仍由玩家设定，并不意味着可从白毛观察出来。
